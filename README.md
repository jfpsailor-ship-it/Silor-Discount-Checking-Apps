# ডিসকাউন্ট স্ক্যানার (PWA)

মোবাইলের ব্যাক ক্যামেরায় বারকোড স্ক্যান করলেই দেখাবে: **৫০% / ৩০% / নন-ডিসকাউন্ট**, ডিসকাউন্টের পর দাম, **ভ্যাটসহ কাস্টমার প্রাইস** (গার্মেন্টস ১০%, একসেসোরিজ ৭.৫%), স্টক, ক্যাটাগরি ও অন্যান্য তথ্য।

## ডিসকাউন্টের নিয়ম
| শর্ত | ডিসকাউন্ট |
|---|---|
| A02 (সিজন) এর বছর ≤ 2024 | ৫০% |
| স্টাইল+কালার ৩০% লিস্টে আছে | ৩০% |
| বাকি সব | নেই |

দুই নিয়ম একসাথে মিললে বেশি ডিসকাউন্টটি ধরা হয়। নিয়ম ও ভ্যাট অ্যাপের **ডেটা** ট্যাব থেকে বদলানো যায়।

## প্রথমবার GitHub-এ চালু করা
1. github.com → **New repository** → নাম দিন (যেমন `discount-scan`) → **Public** → Create।
2. **Add file → Upload files** → এই ফোল্ডারের **সব ফাইল ও ফোল্ডার** (`index.html`, `sw.js`, `manifest.webmanifest`, `.nojekyll`, `js`, `css`, `libs`, `icons`, `data`) টেনে এনে **Commit changes**।
3. **Settings → Pages → Branch: `main` / `(root)` → Save**।
4. ১–২ মিনিট পর লিংক পাবেন: `https://আপনার-ইউজারনেম.github.io/discount-scan/`

> ⚠️ Public রিপোতে `data` ফোল্ডারের ফাইল সবাই দেখতে পারে। তাই অ্যাপ শুধু দরকারি কলাম (বারকোড, স্টাইল, সাইজ, MRP, স্টক ইত্যাদি) রাখে — **কস্ট/CPU কখনো থাকে না**।

## স্টক বা ডিসকাউন্ট আপডেট (সবার জন্য)
1. অ্যাপ খুলে **ডেটা** ট্যাবে যান।
2. **স্টক ফাইল** বাছুন (Stock Report .xlsx)। নতুন ডিসকাউন্ট শিট থাকলে **%** লিখে ডিসকাউন্ট ফাইল বাছুন।
3. **⬇ stock.json** / **⬇ discounts.json** ডাউনলোড করুন (কম্পিউটারে করা সহজ)।
4. GitHub রিপো → `data` ফোল্ডার → **Add file → Upload files** → ফাইল দুটি দিন (একই নাম, পুরোনোটি বদলে যাবে) → **Commit**।
5. ১–২ মিনিট পর সব ফোনে অ্যাপ খুললেই নতুন ডেটা আসবে (ইন্টারনেট থাকলে)।

## অন্য আউটলেট
- **সহজ:** নিজের ফোনেই অ্যাপ খুলে ডেটা ট্যাবে নিজের স্টক ফাইল দিন → **এই ফোনে ব্যবহার করুন**। (শুধু ঐ ফোনে থাকবে।)
- **সবার জন্য:** রিপো **Fork** করে নিজের GitHub-এ নিন, উপরের ধাপে নিজের `stock.json` আপলোড করুন, নিজের Pages লিংক ব্যবহার করুন।

## ফোনে ইনস্টল
- **Android (Chrome):** ডেটা ট্যাবের "অ্যাপ ইনস্টল করুন" বোতাম, বা ⋮ → Install app।
- **iPhone (Safari):** Share → Add to Home Screen।

## স্ক্যানের টিপস
- বারকোড লাল ফ্রেমের ভেতরে রাখুন, ৮–১৫ সেমি দূর থেকে। অন্ধকারে 🔦 ফ্ল্যাশ, ছোট বারকোডে জুম (1×/2×/3×)।
- সফল হলে ফ্রেম **সাদা** হবে, ফোন কাঁপবে (iPhone-এ ভাইব্রেশন সীমিত, বিপ শব্দ থাকবে)।
- ক্যামেরা না চললে ব্রাউজারে ক্যামেরা Allow করুন।
